# RIIC-Assistant

This is a base rotation planer for [Arknights](https://www.arknights.global/), a game developed by Hypergryph.

## Techstack

Rica is developed with [TanStack Start](https://tanstack.com/start/latest) in Typescript.
UI made with [Tailwind CSS](https://tailwindcss.com/) and [Shadcn](https://ui.shadcn.com/).

## Instructions

### Run

```bash
pnpm install
pnpm dev
```

### Linting & Formatting:

This project uses [Biome](https://biomejs.dev/) for linting and formatting.
The following scripts are available:

```bash
pnpm lint
pnpm format
pnpm check
```
