## Instructions

### Run

```sh
pnpm install
pnpm dev
```

### Build

```sh
pnpm build      # Build Prod
pnpm preview    # Preview build
```

### Linting & Formatting:

```sh
pnpm lint           # Check code correctness
pnpm format         # Format code
pnpm format:check   # Check code format
```
